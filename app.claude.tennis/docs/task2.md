# Users Page
The users page should have the following functionality
* The ability to add a user:
  * First Name, Last Name, rank 1-3, comment
* View a list of users,
  * Showing the First Name and Last name and an edit button.
  * Sort options alphabetically by first name or last name. desc or ascending
* Search for users

In the user edit detail page. The following form is shown
* First Name, Last Name, Drop down list showing None,1-3, Comment: text area
* A save button
* A delete user button
  * When clicked a confirmation dialog must be shown.

On entry to the page the user list is shown.
The sort options should be saved and applied when the application is closed and re-opened
The user list must persist on the phone when the app is closed and re-opened.
